# 브로드 가의 펌프 · 1854 소호 콜레라 조사단

1854년 런던 소호의 콜레라 유행을 무대로, 학생이 조사관이 되어 집집마다 문을 두드리고
기록을 견주어 원인을 찾아내는 웹 수업용 게임이다. 혼자서도 끝까지 할 수 있고, 같은 방 번호로 들어온 학급 친구들과 한 지도 위에서 함께 조사할 수도 있다.

## 수업에서 겪게 하려는 것

1. **같은 질문을 모두에게** — 누가 죽었는지, 공기는 어떤지, 마실 물은 어디서 긷는지를 14곳에서 똑같이 묻고 적는다.
2. **예상하고 확인하기** — 가기 전에 먼저 예상을 적는다. 당국의 생각대로라면 가장 비좁고 냄새나는 곳에서 가장 많이 죽어야 한다. 구빈원(535명 중 5명)과 양조장(70명 중 0명)이 그 생각을 깬다.
3. **비교와 추리** — 수첩에서 기록을 악취로, 또 마신 물로 묶어 본다. 어느 쪽이 죽음을 가르는지 스스로 찾는다.
4. **가설 검증** — 펌프 곁에 살아도 마시지 않은 사람은 무사한가, 멀리 살아도 마신 사람은 앓는가.
5. **설득** — 공기설을 믿는 교구 위원들의 반박마다 알맞은 기록 한 장을 내놓는다.
6. **실제 역사** — 손잡이를 뗀 뒤의 이야기(이미 수그러들던 유행, 40번지 아기와 정화조, 받아들여지지 않은 결론)를 사실대로 전한다.

주민은 자기가 본 사실만 말한다. 물이 원인이라는 해석은 대사에 없고 학생이 기록에서 찾아낸다.
수첩의 각 기록에는 스노우의 보고서에 실린 사례인지, 당시 기록으로 꾸민 가구인지가 표시된다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D`, 방향키 | 걷기 |
| 지도 누르기 | 길을 따라 그곳까지 걷기. 건물을 누르면 문 앞까지 가서 문을 두드린다 |
| `E` | 문 두드리기, 펌프 살펴보기 |
| `N` | 수첩 (기록 · 비교 · 추리) |
| `M` | 전체 지도 |
| `B` | 학급 상황판 (모둠별 진행, 학급 전체의 사망자 막대) |

지금 할 일까지는 붉은 점선이 길을 따라 안내한다. 진행 상황은 브라우저에 저장되어 새로 고쳐도 이어진다.

## 학급과 함께 하기

방 번호는 필요할 때만 쓴다. 첫 화면에서 `학급 친구들과 함께 하기`를 눌러 선생님이 정한 방 번호를 넣거나,
학급 상황판(`B`)의 `초대 주소 복사`로 만든 주소를 나눠 주면 방 번호가 채워진 채로 열린다. 방 번호를 넣지 않으면 혼자 조사한다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ (GitHub Pages 배포용)
```

## 구조

```
src/data/story.ts      조사 장소 14곳의 대사와 사실, 단계, 쪽지, 위원회, 맺음
src/data/geo.json      장소·펌프 좌표 (원본 지도 픽셀)
src/game/renderer.ts   지도와 인물 그리기
src/game/nav.ts        거리 위 걷기, 길 찾기
src/game/multiplayer.ts 학급 연결 (Playroom Kit)
src/ui/                면담 장면, 수첩
tools/build_assets.py  고지도에서 게임 지도·보행 마스크·도보권역을 만든다
tools/build_buildings.py 주택 그림의 벽돌·창·지붕으로 양조장·공장·구빈원을 같은 화풍으로 합성한다
tools/playtest.mjs     한 판을 처음부터 끝까지 자동으로 돌려 보는 점검
tools/source/          원본 고지도와 고해상도 그림
```

지도는 존 스노우의 1854년 지도에서 사망자 막대를 지워 만들었다. 학생이 조사할 때마다 막대가 쌓이고,
끝난 뒤 스노우의 실제 지도와 견주어 볼 수 있다. 전체 지도의 붉은 길은 걸어서 브로드 가 펌프가 가장 가까운 거리로,
스노우가 두 번째 지도에 그린 경계와 같은 원리로 계산했다.

장소나 좌표를 바꾼 뒤에는 `python tools/build_assets.py` 를 다시 돌린다 (numpy, opencv-python, scipy, pillow 필요).
