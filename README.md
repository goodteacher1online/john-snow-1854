# 1854 런던 소호 콜레라 역학 조사단 (John Snow 1854)

> **"나쁜 공기(Miasma) 때문인가, 보이지 않는 오염된 물 때문인가?"**  
> 1854년 런던 소호 거리를 배경으로 한 웹 기반 멀티플레이어 역학 조사 시뮬레이션 RPG

---

## 📖 교육적 배경 및 게임 목표
1854년 런던에 콜레라가 창궐했을 때, 당시 의학계와 당국은 콜레라가 악취와 나쁜 공기(Miasma, 장기설)로 전염된다고 굳게 믿었습니다.  
의사 **존 스노우(John Snow)**는 이 편견에 맞서 실제 사망자가 발생한 가정을 가가호호 방문 조사하였고, 데이터를 지도 위에 점(Dot)으로 시각화하여 **'브로드 스트리트의 특정 공공 식수 펌프'**가 감염의 진원지임을 증명해 냈습니다.

이 시뮬레이션에서 학생들은 당시의 역학 조사관이 되어 다음을 경험합니다:
1. **편견(장기설)의 함정**: 게임 시작 시 하수구와 도살장 주변에 안개가 깔리며 공기 전염설을 의심하게 됩니다.
2. **이상치(Outlier)의 발견**: 
   - 하수구 바로 옆 맥주 양조장(Brewery) 노동자 70명 중 사망자 0명! (물 대신 맥주만 마심)
   - 극빈층 구빈원(Workhouse) 535명 중 사망자 극소수! (자체 깊은 우물 사용)
   - 소호에서 멀리 떨어진 햄스테드(Hampstead) 귀부인의 사망! (브로드 펌프 물을 마차로 배달해 마심)
3. **공간 통계와 데이터 시각화의 위력**: 각 조가 수집한 데이터가 지도에 합쳐지며 펌프 중심의 완벽한 동심원 패턴을 스스로 목격합니다.
4. **역사적 결단**: 브로드 스트리트 펌프 손잡이를 제거하여 콜레라 확산을 멈춥니다.

---

## 🎮 플레이 방법 & 조작법
* **이동**: `W`, `A`, `S`, `D` 또는 `방향키` (모바일/태블릿: 화면 좌측 하단 D-Pad)
* **가구 방문 및 인터뷰**: 집 문 앞 근처에서 `E` 키 (모바일: 화면 우측 '조사' 버튼)
* **전체 역학 지도 보기**: `M` 키 (줌아웃하여 도시 전체 패턴 조망)
* **공기 안개 켜기/끄기**: 상단 `안개` 버튼 클릭
* **펌프 손잡이 제거**: 브로드 스트리트 펌프 접근 후 `Space` 키

## 🛠️ 기술 아키텍처
* **클라이언트**: Vanilla TypeScript + HTML5 Canvas (무지연 벡터 고지도 렌더링) + Tailwind CSS
* **멀티플레이어**: Playroom Kit (P2P / WebSocket 하이브리드 서버리스 동기화, 10Hz 위치 보간)
* **배포**: GitHub Pages 호스팅 (서버 운영비 0원)
